# Безопасность Search

Публичных выпусков браузера пока нет. Исследовательские материалы и прототипы могут содержать ошибки; не используйте их как ежедневный браузер для важных данных.

Если нашли уязвимость, откройте вкладку **Security** этого репозитория и выберите **Report a vulnerability**. GitHub отправит сообщение владельцу приватно. Приложите сценарий воспроизведения, затронутую ОС, версию и возможное влияние. Не публикуйте эксплойт или личные данные в обычном issue.

Владелец подтвердит получение отчёта и согласует дальнейшие шаги через приватное обсуждение GitHub. Сроки исправления заранее не обещаются: проект пока на этапе исследования.
