# Search

Открытый кроссплатформенный браузер для macOS, Windows и Linux. Проект находится на этапе исследования и подготовки. Код браузера ещё не начат.

## Цель

Сделать браузер, которым удобно пользоваться каждый день: быстрый запуск, отзывчивые вкладки, понятные настройки, надёжное хранение данных и предсказуемая работа сайтов. Заявления о скорости будут опираться на измерения, а не на язык реализации.

## Текущий план

- Основной кандидат: оболочка на Rust с Wry и системными веб-движками.
- Экспериментальный кандидат: Servo, движок на Rust.
- Окончательный выбор после прототипов на всех трёх ОС и проверки реальных сайтов.
- Дизайн разрабатывается отдельно до реализации основного интерфейса.

Первый узкий опыт: [Wry smoke на macOS](prototypes/wry-smoke/README.md). Его [протокол](docs/experiments/2026-11-06-wry-macos-smoke.md) отделяет подтверждённые результаты от ещё не проверенных сценариев.
