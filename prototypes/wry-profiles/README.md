# Wry: проверка профилей на macOS

Исследовательский прототип, не браузер Search. Требуется macOS 14 или новее и графическая сессия.

Из корня репозитория:

```sh
cargo run --locked --manifest-path prototypes/wry-profiles/Cargo.toml
```

Прототип открывает три окна каскадом: два постоянных профиля с разными идентификаторами WebKit и одно приватное окно. Их можно различить по заголовкам `Search profile A`, `Search profile B` и `Search private`; для переключения подойдёт Mission Control. После первого закрытия приватное окно автоматически открывается заново один раз, чтобы проверить удаление его данных без перезапуска приложения. Все окна загружают одну локальную страницу с фиксированного адреса `127.0.0.1:43127`. Если порт занят, запуск завершается ошибкой. Закройте все окна для завершения программы.

Проверку по шагам и таблицу результатов см. в [протоколе](../../docs/experiments/2026-11-06-wry-macos-profiles.md). На странице нет внешних скриптов и нет IPC к Rust. Она хранит только введённую тестовую метку. Не вводите туда личные данные.
