# Wry: автоматическая проверка отказа камеры

Узкий macOS-прототип. Он поднимает локальную страницу на случайном порту `127.0.0.1`, запрашивает камеру через `getUserMedia` и всегда отвечает `Deny` в обработчике Wry. Поток камеры не должен открываться. Программа завершается с кодом 0, только если страница получила `NotAllowedError` и macOS-обработчик Wry был вызван.

Из корня проекта:

```sh
cargo run --locked --manifest-path prototypes/wry-permission-deny/Cargo.toml -- --request-camera
```

Ключ `--request-camera` обязателен, чтобы случайный запуск не показал системный запрос macOS. Не запускайте этот бинарник как автоматическую CI-проверку: решение по системному запросу принимает человек. Если страница получает отказ, а обработчик Wry не вызывается, программа завершится с кодом 1 и запишет `camera handler calls: 0`. Это неопределённый результат для обработчика, а не доказательство его работы.

Прототип не проверяет привязку разрешения к origin, сохранённые разрешения, геолокацию или другие ОС. Не вводите личные данные на тестовой странице.
