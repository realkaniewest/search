# ServoShell Windows runtime probe

Исследовательский сценарий для официального ServoShell v0.8.0. GitHub Actions запускает `run.ps1` на `windows-2025`; сценарий не собирает Servo из исходников и не встраивает его в Search.

Скрипт скачивает официальный ZIP, сравнивает SHA-256 до распаковки и запуска, открывает локальную страницу на `127.0.0.1:43132` в отдельном временном профиле, проверяет HTTP GET и цвет, который JavaScript установил в PNG. Время запуска ограничено, временные процессы и файлы убираются в `finally` насколько позволяет система.
