# Search: интерактивный макет оболочки

Откройте `index.html` в любом современном браузере. Файлу не нужны сервер, сборка, сеть или сторонние ресурсы.

Это исследовательский макет **интерфейса**, а не браузер Search. Он не открывает реальные сайты, не хранит историю, не запрашивает разрешения и не проверяет движок. Строка адреса принимает только названия демонстрационных страниц: `Код`, `Заметки`, `Видео`, `Дизайн`, `Чтение`, `Форум`, `Новости`, `Места`, либо `demo://code` и аналогичные адреса.

Для проверки доступны вкладки сверху, открытие избранного в новой вкладке, переключение, закрытие, переход назад и вперёд внутри демостраниц, светлая тема и узкое окно. Сочетания клавиш: ⌘/Ctrl+T, ⌘/Ctrl+W, ⌘/Ctrl+L; стрелки влево и вправо при фокусе на вкладке. Значки и названия демонстрационные. Логотип, точные цвета, размеры, поведение стекла и доступность требуют дальнейшей проверки в настоящем приложении на macOS, Windows и Linux.

Проверка модели вкладок, фокуса и переключателя темы: `node prototypes/ui-shell/check-ui.mjs` из корня проекта. Это проверка событий на простой модели DOM, она не заменяет визуальную проверку в браузере и проверку экранным диктором.
