# ServoShell v0.8.0: macOS profile probe

Это отдельный исследовательский тест, не часть браузера Search. Он запускает официальный ServoShell с временными каталогами A, B и P на одном локальном origin. Для P используется `--temporary-storage`. JavaScript записывает вымышленные cookie и `localStorage`; две большие ячейки PNG показывают результаты независимо. Перед проверкой данных идут контрольные зелёная и красная страницы, чтобы учесть фактическую цветопередачу PNG на этом Mac. Белый, серый и неизвестный цвет останавливают тест. Локальный сервер отдаёт только `/probe.html`.

После проверки SHA-256 официального DMG и подключения образа запустите:

```sh
python3 prototypes/servo-mac-profiles/run.py /Volumes/Servo/Servo.app/Contents/MacOS/servoshell
```

Нужны macOS, Python 3, Swift compiler и ServoShell v0.8.0. Скрипт выделяет свободный порт на `127.0.0.1`, сначала проверяет контрольную отрисовку без обращения к хранилищу, ограничивает каждый основной процесс 45 секундами, выводит JSON по каждому сценарию и имена/размеры файлов временного профиля P после завершения основного процесса. Содержимое файлов не печатается; для вымышленной метки проверяются первые 2 MiB каждого файла. Потомки ServoShell отдельно не отслеживаются, поэтому список файлов и очистка не доказывают, что все процессы уже завершились. Временные профили, PNG и вспомогательная программа удаляются при обычном выходе; при аварии ОС очистка не гарантирована. Если страница не раскрасилась, отдельная временная папка с одним PNG сохраняется для диагностики, её путь печатается в выводе. На Windows и Linux этот сценарий не запускался.

`pass` означает совпадение с ожиданием конкретной строки по цвету, откалиброванному двумя контрольными снимками. Для `P_reopen_empty` это означает, что значение не читается после перезапуска; для `P_reopen_P` совпадение означает сохранение значения. В конце скрипт выводит JSON `verdict` с отдельными полями для cookie и `localStorage`. `temporary_storage_meets_probe_criterion` требует пустого P после перезапуска и отсутствия вымышленной метки в первых 2 MiB файлов. Код выхода 0 возможен, только если одновременно истинны `A_B_cookie_checks_pass`, `A_B_localStorage_checks_pass` и `temporary_storage_meets_probe_criterion`. Если хотя бы одно поле ложно, `all_probe_criteria_pass` ложно, вывод сохраняется и код выхода равен 2. Код 0 означает только прохождение узкого сценария, а не готовность полноценного приватного режима. Логику трёх условий проверяет `python3 prototypes/servo-mac-profiles/test_verdict.py`. Результат запусков на Mac записан в [отчёте](../../docs/experiments/2026-11-11-servo-macos-profiles.md).
