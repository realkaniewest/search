# Локальные страницы для сравнения движков

Запуск из корня проекта:

```sh
python3 -m http.server 43128 --bind 127.0.0.1 --directory prototypes/engine-fixtures
```

Откройте `http://127.0.0.1:43128/basic.html`. Страница не загружает внешние ресурсы и не содержит личных данных. После нажатия кнопки заголовок вкладки меняется с `Search fixture: ready` на `Search fixture: clicked`.

Для отдельной проверки скачивания запустите `python3 prototypes/engine-fixtures/download_server.py` из корня проекта и откройте `http://127.0.0.1:43129/page`. Страница через секунду нажмёт ссылку на `/download`. Сервер отдаёт фиксированный файл с `Content-Disposition: attachment` и именем `search-servo-v070-probe.txt`. Перед повтором проверьте, нет ли такого файла в папке загрузок. Сервер слушает только `127.0.0.1`; остановка через `Ctrl-C`.

Для проверки настоящего клика откройте `http://127.0.0.1:43129/manual`: это та же ссылка без автоматического JavaScript-нажатия. Нажмите `Download test file` в окне проверяемого движка.
