# Wry smoke test

Отдельный исследовательский прототип только для macOS. Это не браузер Search и не дизайн его интерфейса. Сборка на Windows и Linux намеренно заблокирована до проверки WebView2/SmartScreen и GTK/Wayland.

## Запуск на macOS

Из этой папки выполните `cargo run --locked` в обычной графической сессии Mac, например в Ghostty. Требуются Rust и Xcode Command Line Tools. Ожидается одно окно с заголовком `Search: Wry smoke test`, русским текстом и ссылкой на сайт Rust. Закрытие окна должно завершить процесс. Проверяется только факт внешнего перехода, не содержимое сайта.

Статическая страница передаётся в Wry через `with_html`. Для неё Wry указывает null origin. WebView запускается с `with_incognito(true)`, но этот опыт не доказывает изоляцию профилей или удаление данных. Навигация после перехода на сайт Rust не ограничена политикой Search. Все запросы разрешений, которые Wry передаёт в обработчик, явно отклоняются; полнота покрытия разных типов разрешений ещё не проверена. Не используйте здесь личные аккаунты. Прототип ничего не доказывает о загрузках или безопасности внешней навигации. [Документация Wry](https://docs.rs/wry/latest/wry/struct.WebViewBuilder.html).

Результаты и версии записываются отдельно в `docs/experiments/`. Windows и Linux пока не проверены.
