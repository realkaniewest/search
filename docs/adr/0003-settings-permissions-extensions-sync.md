# Разрешения, расширения и синхронизация Search

Статус: предложено для проверки. Задача [#112](https://github.com/realkaniewest/search/issues/112). До отдельного принятия действует [ADR 0002](0002-macos-https-preview.md).

## Разрешения сайтов

На macOS нативный обработчик WebKit получает origin, фрейм и тип запроса. Закреплённый интерфейс Wry передаёт Search только тип. До интерфейса разрешений проверить адаптер, который сохраняет схему, хост, порт и сведения о фрейме. Показать источник запроса в нативном диалоге. По умолчанию отказывать, в том числе при смене страницы во время диалога, для вложенного фрейма и при отсутствии сведений об источнике. Существующая политика временных окон остаётся запретом на этом этапе. [WKUIDelegate](https://developer.apple.com/documentation/webkit/wkuidelegate?changes=lat_4&language=objc)

Приёмка первого сценария проверяет два сайта, отдельные решения для камеры и микрофона, отмену при навигации, смену фрейма, отзыв разрешения, перезапуск и временное окно. Геолокацию проверять отдельно через предусмотренный для неё нативный обработчик. Список данных сайтов оперирует именами групп WebKit. Эти имена непригодны для выдачи разрешений по origin.

## Расширения

Проверить нативный WKWebExtensionController на поддерживаемой версии macOS с тестовым расширением, устанавливаемым явным действием. В карточке установки показывать возможности и сайты, к которым расширение просит доступ. Давать доступ только к подтверждённым сайтам. Загрузку, выключение и удаление проверять на обычном профиле. У тестового расширения нет доступа к внутренней панели, IPC браузера или временным окнам. Заявлять поддержку только для проверенных API и форматов. [WebKit extension controller](https://developer.apple.com/documentation/webkit/wkwebextensioncontroller/configuration-swift.class)

На Mac локальное расширение Manifest V3 выполнило скрипт на разрешённом адресе. Маркер отсутствовал на явно запрещённом адресе, в отдельном WebView без контроллера, загрузившем HTML панели Search, во временном WebView с тем же контроллером и после отзыва разрешения и перезагрузки страницы. Запуск: `python3 prototypes/webkit-extensions/run.py` на macOS 15.4 или новее. Проверка использует локальный сервер и удаляемый профиль. Во вложенном фрейме разрешённого сайта маркер появился только на разрешённом адресе. Тест с тремя отдельными процессами проверил сохранение решения вне непостоянного контроллера, восстановление выдачи доступа и сохранение отзыва после следующего перезапуска. Этот путь требует собственного хранилища решений Search. Для приёмки остаются интеграция с обычным профилем Search, панель в запущенном браузере и IPC.

## Синхронизация

Первый сценарий переносит выбранные браузерные предпочтения и закладки между двумя устройствами. История, данные сайтов, разрешения, локальные пути, содержимое вкладок и временные данные находятся вне этого сценария. Выбор способа синхронизации зависит от доступного подписанного приложения и проверки двумя устройствами.

Для эксперимента с пользовательской папкой iCloud Drive нужны выбор папки в системном диалоге, согласованные файловые операции в фоне, версия формата и обработка параллельных правок. Обычная запись файла с заменой не годится для двух устройств. Проверить правку без сети, конфликт, отмену подключения и обработку повреждённого файла. [Файловая координация Apple](https://developer.apple.com/documentation/Foundation/improving-performance-and-stability-when-accessing-the-file-system)
