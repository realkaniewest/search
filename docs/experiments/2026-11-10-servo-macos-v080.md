# ServoShell v0.8.0: локальные сценарии на macOS

Статус: выполнены два узких опыта с официальным выпуском на Mac 10 ноября 2026 года. Это готовый ServoShell, не встраивание движка в Search.

## Среда

- macOS 27.0.1, Apple Silicon arm64, Mac17,3, 16 GiB RAM; Rust 1.99.1. Для сборки Servo из исходников по [инструкции проекта](https://book.servo.org/building/macos.html) нужен полный Xcode. На этой машине `xcodebuild -version` не работает: активны только Command Line Tools. Сборка исходников не проводилась.
- Официальный [Servo v0.8.0](https://github.com/servo/servo/releases/tag/v0.8.0), коммит `4e136d8ef31b7c4748fbfac606ca463f3efd7537`, `servo-aarch64-apple-darwin.dmg`, опубликованный SHA-256 `bfdc69c789f4214e72955520a81a6ea20142bf1f306001f4bf478917728e9361`. Локальный `shasum -a 256` совпал. Образ подключён только на время опыта, приложение не копировалось в `/Applications`.
- Использовались локальные страницы Search на `127.0.0.1`. Личные аккаунты и внешние сайты не открывались.

## Наблюдения

| Сценарий | Результат |
| --- | --- |
| Базовая страница | ServoShell запущен с `--headless --exit --output` и отдельным временным профилем. Сервер получил `GET /basic.html` 200, процесс завершился с кодом 0. Получен снимок 1024×740 с читаемым русским заголовком, текстом и кнопкой. JavaScript-нажатие кнопки в этом запуске не проверялось. |
| Скачивание по обычному клику | В окне ServoShell открыта `/manual`, ссылка `Download test file` нажата через UI. Сервер записал `GET /manual` 200 и `GET /download` 200. Адресная строка перешла на `/download`; содержимое окна показало `Unknown content type (application/octet-stream)`. В `~/Downloads` и временном профиле Servo ожидаемый `search-servo-v070-probe.txt` не найден. В журнале есть `unknown completed load PageSource(...)`. |
| Завершение | Окно и локальные серверы остановлены, образ отключён. |

Результат скачивания совпадает по видимому поведению с [прошлым опытом на v0.7.0](2026-11-07-servo-macos-manual-download.md). Это не доказывает отсутствие всех способов загрузки в Servo: не проверены другой MIME-тип, другие каталоги и встраивание. Поиск файла не охватывал весь диск.

## Границы результата

Не проверены профили и приватный режим, разрешения, медиа, доступность, реальные сайты, Windows/Linux, сборка из исходников и внедрение Servo в Search. Предупреждения о таймере, текстуре и профилировщике были в логе, но тест базовой страницы завершился с кодом 0. Скорость и память не измерялись.

Снимок базовой страницы просмотрен визуально и оставлен только во временной папке; в репозиторий не добавлен. Следующий опыт должен сравнить одинаковые сценарии Wry и Servo на закреплённых версиях, включая файлы, разрешения и изоляцию данных, перед архитектурным решением.
