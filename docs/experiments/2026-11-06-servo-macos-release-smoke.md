# Servo 0.7.0: первый smoke на macOS

Статус: выполнен узкий запуск официального `servoshell`. Это проверка готового демонстрационного приложения Servo, а не встраивания движка в Search и не сравнение скорости с Wry.

## Среда и артефакт

- 6 ноября 2026 года, macOS 27.0.1, Apple Silicon, Mac17,3, 16 GiB RAM.
- Официальный [выпуск Servo v0.7.0](https://github.com/servo/servo/releases/tag/v0.7.0), коммит `aac43a3f31a259f04a574f5ec4e959c943ad7cc7`.
- `servo-aarch64-apple-darwin.dmg`, размер 114699280 байт, SHA-256 `1f9b5b6e4b97a499e8c68e6b52527b904916eca9b0b90f472e4b0ebde73d3014`. Вычисленная контрольная сумма совпала с суммой в выпуске. Образ подключён только для теста, приложение не устанавливалось в `/Applications`.
- Локальная тестовая страница: [`prototypes/engine-fixtures/basic.html`](../../prototypes/engine-fixtures/basic.html), HTTP на `127.0.0.1:43128`.

## Ограничения

Проверка интерфейса выполнена через доступные действия окна Mac, без участия владельца. Дерево доступности показывало элементы оболочки Servo и заголовок вкладки, но не текст веб-страницы. Это наблюдение не доказывает ни поддержку, ни отсутствие поддержки экранного диктора: нужен отдельный тест доступности. Кнопка на тестовой странице сработала с клавиатуры.

Скриншот в репозиторий не сохранялся. Основание для результатов: наблюдавшиеся заголовки и элементы окна, визуальный просмотр локальной страницы и ответ локального сервера `GET /basic.html HTTP/1.1` с кодом 200. Измерения времени и памяти не проводились.

Этот опыт не даёт основания выбирать Servo для Search. По [Servo Book](https://book.servo.org/) встраивание в виде WebView всё ещё развивается. До ADR нужно проверить реальные сайты, безопасность, приватные данные, медиа, процессы и стоимость поддержки, затем сравнить с Wry на тех же условиях.
