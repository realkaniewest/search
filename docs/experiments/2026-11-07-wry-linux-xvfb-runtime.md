# Wry 0.57.1: первый запуск WebKitGTK в Linux CI

Статус: исследовательский прототип запустился на Ubuntu 24.04 под Xvfb. Встроенная страница выполнила JavaScript и изменила заголовок, который получил Rust callback. Пиксельная отрисовка не проверена.

## Среда и процедура

- 7 ноября 2026 года, GitHub Actions `ubuntu-24.04` с Xvfb (виртуальный X11-экран 1280×800×24), Wry 0.57.1, Tao 0.37.2, Rust 1.99.1. Код и команды: [`prototypes/wry-linux-runtime`](../../prototypes/wry-linux-runtime/README.md).
- Установлены `libwebkit2gtk-4.1-dev`, `xvfb`, `xauth`. CI выполнил форматирование, Clippy с `-D warnings`, сборку с закреплённым `Cargo.lock`, затем запустил бинарник через `xvfb-run`.
- Прототип создал окно Tao и WebKitGTK через `build_gtk`, загрузил только локальный HTML. Скрипт изменил текст в DOM и `document.title` на `Search Linux smoke ready`. Rust принимал только точное совпадение заголовка; внутренний таймаут 20 секунд давал код 1. Внешний таймаут CI увеличен до 90 секунд, чтобы учесть запуск WebKitGTK до начала внутреннего таймера.

## Наблюдения

- [Первый CI-прогон PR #21](https://github.com/realkaniewest/search/actions/runs/42382318520/job/128432334788) с внешним таймаутом 40 секунд завершился успешно за 2 мин 37 с. В шаге `Run under Xvfb` журнал содержит `TITLE Search Linux smoke ready` и `PASS: local HTML changed the document title via JavaScript`. Лимит 90 секунд установлен после этого прогона.
- Журнал также содержит предупреждение об отсутствии `org.a11y.Bus` и предупреждения `libEGL` о DRI3/ускоренном рендеринге. Они не остановили сценарий. Доступность и качество графической отрисовки этими логами не подтверждены.
- Проверки сборки Wry на Windows и Linux, а также существующий macOS CI в этом же прогоне прошли. Это отдельные проверки, не часть Linux UI-сценария.

## Вывод и границы

На Ubuntu runner под Xvfb удалось запустить Tao/WebKitGTK и выполнить JavaScript локальной страницы. Это сильнее прежней проверки одной сборки. Пока не проверены видимые пиксели, взаимодействие мышью и клавиатурой, реальные сайты, Wayland, звуковое/видео-воспроизведение, разрешения, сохранение и очистка профиля, пользовательские дистрибутивы Linux. Отдельный Linux GUI-прогон остаётся нужен до готового браузера. Время CI не является скоростью запуска браузера.
