# ServoShell v0.8.0: Linux runtime probe

Статус: подготовлен воспроизводимый CI-опыт для [задачи #31](https://github.com/realkaniewest/search/issues/31). Результат запуска в Ubuntu и Xvfb нужно заполнить по журналу CI после PR. Это проверка официального ServoShell, а не встроенного движка Search.

## Зафиксированные входные данные

- [Servo v0.8.0](https://github.com/servo/servo/releases/tag/v0.8.0), архив `servo-x86_64-linux-gnu.tar.gz`, SHA-256 `02a78892746e69bc39d471da2bb012fd8ce228e464cda5a017334d0e88c61de1` из официального выпуска.
- 10 ноября 2026 года архив скачан во временную папку на Mac; локально вычисленный SHA-256 совпал с опубликованным. Список файлов архива содержит `servo/servoshell` и `servo/resources/`. Это проверка целостности и состава архива, не запуск Linux-бинарника.
- [Локальная fixture](../../prototypes/servo-linux-runtime/probe.html) подаётся с `127.0.0.1:43131`. В HTML серый прямоугольник; JavaScript меняет его на `#14b8a6` и заголовок страницы.
- [Скрипт](../../prototypes/servo-linux-runtime/run.sh) скачивает архив по HTTPS, сравнивает SHA-256 перед распаковкой, запускает отдельный временный профиль, проверяет GET страницы и число цветных пикселей на снимке виртуального экрана. Проверка готовности сервера отправляет только HEAD, поэтому она не создаёт проверяемый GET. При обычном выходе, TERM и INT скрипт пытается остановить прямые дочерние процессы и удалить временные файлы; завершение возможных потомков Servo этим не доказано. CI ограничивает время 180 секундами.

## Матрица результата

| Проверка | Результат |
| --- | --- |
| Контрольная сумма архива и наличие `servoshell` | Проходит на Mac при подготовке |
| Сборка или запуск Servo из исходников | Не проверено |
| Запуск Linux-бинарника под Ubuntu 24.04 и Xvfb | Ожидает CI |
| HTTP-загрузка fixture и JavaScript-отрисовка | Ожидает CI |
| Ввод, реальные сайты, загрузки, медиа, профили | Не проверено |
| Встраивание Servo в Search | Не проверено |

Снимок изолированного Xvfb-экрана нужен только для машинной проверки пикселей; в репозиторий не сохраняется. Это не точный захват окна Servo. Другие окна в этом отдельном Xvfb-сеансе не запускаются, но проверка не доказывает геометрию окна. Этот опыт не даёт чисел для сравнения скорости с Wry и не подтверждает работу на физическом дисплее Linux или Wayland.
