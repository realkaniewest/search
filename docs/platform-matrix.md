## Подтверждённые границы

- У Wry системные движки различаются по ОС: WKWebView на Mac, WebView2 на Windows и WebKitGTK на Linux. Поэтому успешный сценарий на одной ОС нельзя переносить на другую без проверки. [Wry](https://github.com/tauri-apps/wry/tree/wry-v0.57.1).
- ServoShell является тестовой оболочкой движка. Его запуск на трёх ОС не доказывает, что Servo можно безопасно встроить в Search с нужными профилями, разрешениями и загрузками. [Servo Book](https://book.servo.org/trying/getting-servoshell.html), [состояние встраивания](https://book.servo.org/embedding/overview.html).
- Чисел скорости и памяти на одинаковых устройствах нет. Ни один движок пока не объявляется быстрее.

## Что блокирует ADR

1. Проверить одинаковые версии локальных страниц и набор обычных сайтов для Wry и Servo: навигацию, окна, авторизацию, файлы, медиа и сбои. Успех простого HTML не равен совместимости повседневных сайтов.
2. Доказать безопасное решение по разрешениям с origin запрашивающего frame, сохранением и отзывом доступа на каждой ОС. [Аудит Wry](experiments/2026-11-10-wry-origin-permissions.md) пока выявил пробел общего API.
3. Проверить постоянные профили, приватное окно и удаление данных на Windows и Linux, а для Servo на всех ОС. У Wry на Mac проверены лишь тестовые cookie и `localStorage`, включая очистку этих меток. Полное удаление хранилища, cache, истории и разрешений ещё не проверено.
4. Повторить скачивание на одинаковой fixture, разобраться с результатом Servo на Mac и проверить ошибки, выбор места и загрузку файла на других ОС.
5. Проверить реальный GUI на Windows-ПК, Linux под X11 и Wayland, доступность с клавиатуры и экранным диктором. CI и Xvfb дают только часть ответа.
6. Измерить холодный запуск, память 1/10/30 вкладок и задержку навигации на каждой целевой ОС, сравнивая движки на том же устройстве с повторениями. Затем оценить сборку, обновления и стоимость поддержки движка.

Порядок и критерии опытов заданы в [плане прототипов](prototype-plan.md). Пока эти проверки не закрыты, [дорожная карта](roadmap.md) остаётся на этапе 0.
