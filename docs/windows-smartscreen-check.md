# Проверка SmartScreen в Search на Windows

Статус: сценарий подготовлен. Прогон на физическом Windows-ПК ещё не выполнен. Объект проверки: предупреждение о репутации URL внутри WebView2, а не проверка скачанного приложения при его запуске.

## Подготовка

1. Записать версию и номер сборки Windows, архитектуру ПК, версию WebView2 Runtime, версию Edge и коммит Search. Использовать обычную учётную запись с подключением к сети.
2. Записать текущее состояние SmartScreen для Microsoft Edge в Windows Security. Если системная или корпоративная политика выключает проверку, отметить прогон как непоказательный. Настройки и политики в рамках проверки не менять.
3. Проверить конфигурацию панели и вкладок Search: `with_additional_browser_args("")` присутствует у обоих конструкторов. Отдельный тестовый режим может читать `ICoreWebView2Settings8::get_IsReputationCheckingRequired`. Значение `true` проверяет настройку приложения. Системная политика может её переопределить. [Документация API Microsoft](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2settings8?view=webview2-1.0.2849.39)

## Прогон

1. В Edge открыть обычный сайт и затем сценарий **Phishing Page** из [официального тестового набора Microsoft](https://demo.wd.microsoft.com/Page/UrlRep). Зафиксировать, что обычный сайт открывается и в тестовом сценарии появляется предупреждение SmartScreen. На предупреждении остановиться.
2. Подготовить отдельную тестовую сборку Search с тем же конструктором WebView2, теми же аргументами и временным профилем. Разрешить точный HTTPS-адрес выбранного демонстрационного сценария только в этом тесте. Обычная сборка Search ограничивает такую навигацию списком сайтов, поэтому её собственный отказ в переходе не доказывает срабатывание SmartScreen.
3. В тестовой сборке сначала открыть обычный разрешённый сайт, затем точный URL демонстрации. Подтвердить, что предупреждение видимо именно внутри окна Search и относится к этому URL. На предупреждении остановиться. Зафиксировать текст или обезличенный снимок экрана, время и настройку, прочитанную из WebView2, если она доступна.

## Как записать результат

| Наблюдение | Вывод |
| --- | --- |
| Обычный сайт загрузился. Edge и WebView2 Search показали предупреждение на одном демонстрационном URL | Пройден сценарий репутации URL на зафиксированной машине и версии Runtime |
| Edge показал предупреждение, Search открыл страницу без предупреждения | Проверка не пройдена. Произвольную навигацию держать закрытой и проверить версию, политику и настройки WebView2 |
| Edge не показал предупреждение, тестовый адрес недоступен или Search остановил переход собственным правилом | Результат не позволяет судить о SmartScreen в Search |

Успешный прогон относится только к репутации URL. Проверки разрешений, изоляции, скачиваний и остальных условий [ADR 0001](adr/0001-engine-for-first-search-window.md) ведутся отдельно.
