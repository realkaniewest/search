## Этап 1. Рабочий минимум

Окно, адресная строка, вкладки, навигация, один локальный профиль. Демонстрация на macOS, Windows и Linux. Тесты базовой навигации и проверка известных сайтов.

## Этап 2. Ежедневное использование

История, закладки, загрузки, профили, приватное окно, разрешения сайтов, восстановление сессии, клавиатурная доступность.

## Этап 3. Надёжный выпуск

Упаковка под три ОС, подписанные обновления, проверка зависимостей, сценарии сбоя, регрессионные тесты, измерения производительности.

## Этап 4. Расширения

Блокировка контента, импорт данных и возможная система расширений. Синхронизация и Servo рассматриваются по отдельным решениям, после проверки стоимости поддержки.

## Правило завершения задачи

Функция считается готовой только после проверки на затронутых ОС, тестов, ревью другим агентом и обновления документации. Для безопасности и хранения данных нужен отдельный сценарий с отрицательными проверками.
